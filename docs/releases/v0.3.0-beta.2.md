# DuoRelay v0.3.0-beta.2

新增 Linux amd64 单容器部署方式。镜像包含 Web 面板、sing-box、mihomo 和 Cronet，使用 Docker Compose 构建及启动，数据保存在独立卷中。

- 新增 Docker 多阶段构建、非 root 运行和面板健康检查。
- 构建时按 `kernels.lock` 校验内核和 Cronet 文件的 SHA-256。
- 新增 Docker 安装、部署、代理端口、备份和更新文档。

安装步骤参见 [Docker 部署与更新](https://github.com/HlONGlin/DuoRelay/blob/v0.3.0-beta.2/docs/docker-deployment.md)。当前发布的是源码及构建配置，未发布容器镜像到镜像仓库；用户需要在本地运行 `docker compose up -d --build`。默认面板仅绑定宿主机回环地址，TUN 和透明代理需要另行配置与验收。

本次验证了镜像构建、面板健康检查、临时管理员注册、sing-box 代理请求、重启后配置恢复及切换到 mihomo。npm 构建期间报告了现有前端依赖漏洞，尚未在本版本更新相关依赖。
