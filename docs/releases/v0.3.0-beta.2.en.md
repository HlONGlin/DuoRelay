# DuoRelay v0.3.0-beta.2

[简体中文](v0.3.0-beta.2.md) | English

Adds a single-container deployment option for Linux amd64. The image contains the web panel, sing-box, mihomo and Cronet, and is built and started with Docker Compose. Data is stored in a separate volume.

- Added a multi-stage Docker build, non-root runtime and panel health check.
- Docker build verifies SHA-256 hashes for kernels and Cronet against `kernels.lock`.
- Added Docker installation, deployment, proxy-port, backup and update documentation.

See [Docker deployment and updates](../docker-deployment.en.md). The private image is `ghcr.io/hlonglin/duorelay:v0.3.0-beta.2`; pulling it requires an authorized GitHub account and a token with Packages read access. By default the panel binds only to the host loopback address. TUN and transparent proxy require separate configuration and acceptance.

This build was tested for image construction, panel health check, temporary administrator registration, sing-box proxy request, configuration recovery after restart and switching to mihomo. npm reported existing frontend dependency vulnerabilities during the build; related dependencies were not updated in this version.
