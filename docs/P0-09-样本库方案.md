## 样本要求

### 每个协议需要3+样本

**类别1：标准格式**
- 最常见的配置
- 完整的必填字段
- 无特殊选项

**类别2：变体格式**
- 带可选字段
- 不同传输层（WebSocket/gRPC/HTTP2等）
- 不同安全层（TLS/Reality等）

**类别3：边界情况**
- Base64编码差异
- 缺失可选字段
- 特殊字符处理

### 样本格式

```json
{
  "protocol": "shadowsocks",
  "samples": [
    {
      "name": "standard",
      "link": "ss://YWVzLTI1Ni1nY206cGFzc3dvcmQ@example.com:8388#Test%20Node",
      "expected_ir": {
        "protocol": "shadowsocks",
        "server": {"host": "example.com", "port": 8388},
        "proto": {
          "method": "aes-256-gcm",
          "password": "password"
        }
      }
    }
  ]
}
```

## 样本来源

### 1. 手工构造（推荐）
- 优点：可控、安全、完整
- 缺点：需要理解协议格式

### 2. 公开文档
- v2rayN issues
- Clash 示例配置
- sing-box 官方文档

### 3. 测试订阅（慎用）
- 免费节点订阅
- **必须脱敏**：替换真实服务器地址

## 脱敏规则

**必须替换**：
- 服务器地址 → `example.com`, `test.server.com`
- 端口 → 标准测试端口（8388, 443等）
- 密码/UUID → 测试值
- 域名 → `.example.com` 后缀

**保留**：
- 协议字段名称
- 传输层类型
- 加密方法

## 实现建议

### 脚本辅助
```python
# validate_samples.py
import json
import base64

def validate_sample(sample):
    """验证样本格式"""
    assert 'name' in sample
    assert 'link' in sample
    assert 'expected_ir' in sample
    # 检查是否已脱敏
    assert 'example.com' in sample['link'] or 'test.' in sample['link']
    return True

def load_and_validate(file_path):
    with open(file_path) as f:
        data = json.load(f)
    for sample in data['samples']:
        validate_sample(sample)
    print(f"✅ {file_path}: {len(data['samples'])} samples validated")
```
