# P1 阶段任务规划 - MVP开发

**阶段目标**: 实现最小可用产品（MVP），用户可以管理节点和订阅

**预计工期**: 40人日 / 8周（单人）或 4周（双人并行）

---

## P1 任务清单（22个任务）

### 第一周：Parser实现（P1-01~07）

#### P1-01: Parser框架搭建 (1d)
**目标**: 建立统一的解析器接口
- 定义Parser接口
- 实现格式检测（Base64/URI/JSON/YAML）
- 错误处理机制
- 测试框架

**交付**:
- `internal/parser/parser.go` - 接口定义
- `internal/parser/detector.go` - 格式检测
- `internal/parser/parser_test.go`

#### P1-02: Shadowsocks Parser (0.5d)
**目标**: 解析Shadowsocks分享链接
- ss:// URI解析
- SIP002格式支持
- 插件参数解析
- Base64解码

**交付**:
- `internal/parser/shadowsocks/parser.go`
- 使用testdata/samples/shadowsocks_samples.json验证

#### P1-03: VMess Parser (1d)
**目标**: 解析VMess分享链接
- vmess:// URI解析
- Base64 JSON解析

**交付**:
- `internal/parser/vmess/parser.go`

### 第二周：订阅系统（P1-08~10）

#### P1-08: 订阅管理器 (2d)
**目标**: 实现订阅的增删改查
- 订阅CRUD接口
- URL加密存储
- 订阅源管理
- 订阅分组

**交付**:
- `internal/subscription/manager.go` - 完善实现
- `internal/subscription/store.go` - SQLite存储
- `internal/subscription/manager_test.go`

#### P1-09: 订阅解析与更新 (2d)
**目标**: 支持多种订阅格式
- Base64订阅解析
- Clash YAML订阅
- sing-box JSON订阅
- 自动更新机制
- 使用统计提取（subscription-userinfo）

**交付**:
- `internal/subscription/fetcher.go`
- `internal/subscription/parser.go`
- `internal/subscription/updater.go`

#### P1-10: 订阅API (1d)
**目标**: REST API实现
- GET /api/subscriptions - 列表
- POST /api/subscriptions - 添加
- PUT /api/subscriptions/:id - 更新
- DELETE /api/subscriptions/:id - 删除
- POST /api/subscriptions/:id/update - 手动更新

**交付**:
- `internal/api/subscription.go`
- API文档（Swagger）
