## 关键特性

1. **IR到配置的完整映射**
   - Server层 → server/port
   - Transport层 → network/ws/grpc
   - Security层 → tls/reality
   - Proto层 → 协议特定字段

2. **智能过滤**
   - 自动过滤不兼容内核的节点
   - sing-box独有协议不生成mihomo配置
   - mihomo独有协议不生成sing-box配置

3. **配置完整性**
   - DNS配置
   - Inbound配置
   - 路由规则
   - 默认outbound（DIRECT/REJECT）

4. **Golden测试**

   - 确保配置格式稳定
